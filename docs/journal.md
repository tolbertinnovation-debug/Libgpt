# Find and keep your favorite lessons

Open **Library → Journal** to work with everything you have saved.

- Search titles, summaries and the full saved text. All search words must match, in any order.
- Filter by stories, history, wisdom, lessons, names, recipes or pictures.
- Mark an entry as a favorite and select **Favorites only** to find it again.
- Sort by newest, oldest or title.
- Read, listen or download a saved entry as a text file without another AI generation.
- Browse 25 entries at a time. Paging does not remove or limit the saved archive.
- **Undo last removal** restores the last removed entry while the Library instance remains open. Undo is not a permanent recycle bin; make a backup for long-term recovery.

Favorites stay on this device and travel with Grandpa AI backups. Older backups remain compatible. Search updates the results without replacing the search input, so typing stays focused. Storage failures are reported and preserve previously saved data.
